CURRENT NIFTY 500 CASH OHLC REPORTS

Independent tasks:
NSE500 Weekly OHLC — Saturday 09:00 IST.
NSE500 Monthly OHLC — 1st of each month 09:00 IST.
Both include missed-start/sign-in catch-up and three retries 15 minutes apart.
PC must be on and the configured user signed in. Codex/Excel need not be open.
The original daily, weekly F&O and monthly F&O workflows are unchanged.

Output examples:
outputs\2026-11\NSE500 Weekly Nov 9-13 2026.xlsx
outputs\2026-10\NSE500 Monthly Oct 2026.xlsx
Weekly reports belong to the month of Monday. Monthly reports to their month.
The next automatic weekly run is 21 November 2026; monthly 1 December 2026.

Starting universe: the CURRENT official Nifty 500 constituent CSV at generation time.
This is intentionally not point-in-time historical index membership.
Every report records list URL, checksum and download timestamp and includes
the retained Constituents sheet. The official list may contain more than 500
entries after corporate actions.

EXCLUDE F&O STOCKS: remove every index constituent appearing as a stock
underlying (STF/STO) in any official F&O file during that report's sessions.
Match by symbol and cash ISIN aliases, so renamed stocks are excluded too.
This matches the period covered by the separate F&O reports. Retained symbols
are used consistently in the main report, Daily Prices, Coverage and Constituents.
The full official index snapshot remains in nifty500_data, outside the workbook.
Sources and Method records exclusion counts and all CM/FO source checksums.
Versioned receipts regenerate older unfiltered NSE500 reports once.

The 14 November 2026 list contains 501 entries, including DUMMYHEG. That index
placeholder has no cash-market observations for the initial report periods.
It remains visible with n.a. prices and Unavailable classification. No values
are invented. Coverage documents the retained non-F&O stocks and
every stock's available versus expected sessions. Incomplete period coverage
also produces n.a. aggregate prices until complete source coverage exists.

Prices: unadjusted official NSE cash records, INR. Matching prefers ISIN to
handle symbol changes, with a symbol fallback for ISIN changes. Regular
series EQ/BE/BZ/RR are supported; block-deal BL observations are not used.
Original cash symbol and series are retained in Daily Prices.

OHLC: first session open, maximum high, minimum low, final session close.
CPR: same six weekly/monthly categories and three-decimal rounding rules.
TradingView Symbol: symbol followed by a comma, without NSE: prefix.

Official list refreshes for each new generation date. A fresh download failure
leaves the report pending instead of silently using a stale current list.
Offline mode explicitly uses the recorded validated snapshot and cached data.
Current snapshots remain in nifty500_data for auditability.

New or policy-updated reports use the existing secure email sender, with no attachments.
Completed period receipts and event IDs prevent normal duplicate reports/email.
Separate weekly/monthly locks, state files, logs and caches are used.

Config: nifty500_config.json (first_week, first_month, special session overrides).
Run: python nifty500_update.py --kind weekly
Run: python nifty500_update.py --kind monthly
Append --offline to use validated cached sources.
